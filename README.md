# Диктовка – русский голосовой ввод для Kimi (и любых окон Windows)

Kimi Desktop распознаёт голос на своём сервере и русский не понимает – подбирает похожие английские слова. «Диктовка» решает это: распознаёт речь прямо на вашем компьютере (нейросеть Whisper) и вставляет готовый текст туда, где стоит курсор.

## Установка – одна команда

Нажмите **Win+R**, вставьте и нажмите Enter:

```
powershell -ExecutionPolicy Bypass -c "irm https://raw.githubusercontent.com/andrianov28/diktovka/main/install.ps1 | iex"
```

Установщик всё сделает сам: скачает Python, библиотеки и модель распознавания (около 1,6 ГБ, при видеокарте NVIDIA – ещё ~1 ГБ ускорения), положит ярлык на рабочий стол и в автозапуск. Систему не трогает – всё живёт в папке `C:\Diktovka`. Займёт 5–15 минут, зависит от интернета.

## Как пользоваться

1. Поставьте курсор в поле ввода сообщения в Kimi.
2. Нажмите **F8** – внизу экрана загорится красная плашка «Говорите…».
3. Говорите.
4. Нажмите **F8** ещё раз – через пару секунд текст появится в поле. Проверьте и отправьте.

Кнопку микрофона в самом Kimi не нажимайте – она по-прежнему «английская».

Работает в любом окне: браузер, Telegram, Word, Claude.

## Скорость

- С видеокартой NVIDIA – 1–2 секунды на минуту речи.
- Без видеокарты – на процессоре, 5–20 секунд на минуту речи. Если очень медленно – в `config.json` поставьте `"model": "small"` (быстрее, чуть хуже качество).

## Настройки – `C:\Diktovka\config.json`

Открыть: правый клик по значку микрофона возле часов → «Настройки».

| Параметр | Что делает |
|---|---|
| `hotkey` | клавиша записи, например `"f8"`, `"f9"`, `"ctrl+alt+space"` |
| `model` | `"large-v3-turbo"` (лучше) или `"small"` (быстрее) |
| `auto_send` | `true` – сразу отправлять сообщение после вставки |
| `beep` | `false` – без звуков |

После правки – правый клик по значку → «Выход» и запустите ярлык «Диктовка» снова.

## Если что-то не так

- **Ничего не происходит по F8** – проверьте значок микрофона возле часов. Нет значка – запустите ярлык «Диктовка».
- **«Не вижу микрофон»** – Параметры Windows → Конфиденциальность → Микрофон → разрешить приложениям доступ.
- **Остальные ошибки** – файл `C:\Diktovka\diktovka.log`, его можно показать Клоду.

## Удаление

Win+R →

```
powershell -ExecutionPolicy Bypass -File C:\Diktovka\uninstall.ps1
```
